# 形容词 → 设计参数

用户说的形容词只是线索。用这张表把它翻译成具体参数，再复述给用户确认。同一个词，不同的人可能指不同的东西，所以每个词都列出了“常见误读”，确认时可以一并问。

## 高级 / 有质感
- 排版：字重克制，标题大、正文小，字号对比强；精致的无衬线或衬线；小号标签可以略加字距
- 色彩：低饱和，2–3 种颜色加中性色，靠明度而不是色相区分层次；强调色用量极少
- 版式：留白大，内容占比低，对齐严格
- 图像：高质量摄影且调色统一，或者干脆只用排版
- 动效：慢（400–800ms），缓入缓出，位移幅度小
- 常见误读：黑金配色、到处渐变、玻璃拟态、繁复装饰

## 简洁 / 干净
- 一套字体、两三个字重；单色加一个强调色；严格网格；元素少，但每个都对齐
- 动效几乎只用于操作反馈
- 常见误读：空洞。简洁不等于没内容，层级仍然要清楚

## 大气
- 尺度对比极大（全宽图片或巨型标题），留白开阔，模块少而大，对称或强中轴
- 常见误读：把所有东西都放大

## 科技感 / 未来感
- 几何无衬线或等宽字体用于数据；高对比；精确的细线与网格；数据化的细节
- 动效快而精确（150–250ms），线性或强缓出
- 常见误读：紫蓝渐变、霓虹光晕、粒子背景、赛博朋克堆砌

## 年轻 / 活泼
- 圆润字体或粗展示体，高饱和色块，不对称构图，插画
- 弹性动效（spring，带轻微回弹），俏皮的微交互
- 常见误读：颜色越多越好，用 emoji 当图标

## 温暖 / 亲和
- 人文无衬线或柔和的衬线，暖中性色（米、陶土、橄榄），适度圆角，真实人物摄影，口语化文案
- 常见误读：全站米黄色加手写体

## 专业 / 可信
- 经典无衬线，墨色或蓝灰系，信息层级清晰
- 证据前置：案例、数字、客户、方法与局限
- 动效克制
- 常见误读：模板化的企业官网

## 有设计感 / 有个性
- 只有一个明确的签名：独特的字体、非常规网格、一个大胆的色彩决定，或一个让人记住的交互；其余部分保持克制来衬托它
- 常见误读：每一处都要“特别”

## 东方 / 中式
- 留白讲究虚实，中文展示字体（先确认授权），低饱和的传统色而不是大红大金，节奏偏慢，纸张质感克制使用
- 常见误读：祥云、水墨笔刷、印章堆砌

## 国际化
- 中西文混排规范，西文字体与中文字体的视觉大小匹配，图片和措辞避开单一文化语境，布局能容纳不同语言的文本长度
- 常见误读：只做英文版、中文是机翻

## “像某某网站” / “像苹果”
不要照搬。把“像”拆成具体特征，比如“像苹果”通常指：产品摄影为主角、超大标题、极大留白、滚动叙事、极少的颜色。把拆出来的特征逐条复述给用户，问他想要的是其中哪几条。
