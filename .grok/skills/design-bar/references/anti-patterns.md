# 具名反面模式

给反面模式起名字，评审时更容易被识别，也更方便在设计系统的 README 里引用。这些不是绝对禁令：如果它确实服务于项目概念，可以使用，但要在设计系统的 README 里写明理由。

| 名称 | 表现 | 替代思路 |
|---|---|---|
| 渐变病 | 紫蓝或紫粉渐变背景、渐变文字、光晕、斑点 | 从品牌或概念推出色板；纯色加明度层次。渐变只用于有标注的连续数据色阶 |
| 三卡综合征 | 居中标题 → 三张等宽功能卡 → CTA 横条 → 页脚，每个区块都一样 | 根据读者任务决定版式；不等价的内容不要硬塞进等宽格子；重要的给更大的面积 |
| 卡片套娃 | 每个区块、每个数字都装进带边框和阴影的卡片，卡片里再套卡片 | 用间距、对齐和字体分组；容器只用于真正的分组、选中态或警示 |
| 单一字体 | 全站一种字体、一种字重，层级只靠颜色 | 用字号和字重建立层级；按 tokens 定义字体角色 |
| 小灰字 | 为了塞下内容，把正文缩小并调浅 | 先删减、重排、改写，再考虑缩小；正文保持舒适的字号和对比度 |
| 眉标泛滥 | 每个标题上方都有全大写或拉宽字距的小标签、装饰性编号 | 删掉；标题本身写出具体的主张 |
| 指标盒堆叠 | 一排 4–6 个数字卡片，彼此没有关系 | 把数字组织成一个有对比的关系，比如同一刻度上的比较 |
| 图标瓷砖 | 彩色方块里放图标做装饰，风格不统一，或用 emoji 当图标 | 只在能加快识别时用图标，风格统一；大多数情况用文字标签 |
| 胶囊滥用 | 普通元数据、标签都做成圆角胶囊 | 用文字和排版表达；胶囊只用于真正的状态 |
| 全站淡入 | 每个区块滚动时都 fade-up 入场，阅读要等动画 | 默认静止；动效只用于解释状态变化、保持连续性或确认操作；尊重 reduced-motion |
| 炫技动效 | 自定义光标、跑马灯、滚动劫持、全站视差、打字机光标、脉冲状态点 | 留给概念确实需要的那一处签名时刻 |
| 玻璃与噪点 | 玻璃拟态、颗粒噪点、网格背景、纸张模拟、装饰性阴影 | 删掉，用排版和留白建立质感 |
| 空话文案 | “赋能”“一站式”“释放潜能”“开启新篇章” | 写具体的事实、数字、场景和限定条件 |
| 假内容 | 虚构的数据、Logo 墙、用户评价、产品截图 | 用真实内容；没有就留空并标为待补充 |
| 均匀节奏 | 所有区块的上下间距完全相同 | 按关系定间距：组内近、组间远，章节转换更远 |
| 窄表格 | 宽表格被挤在一侧窄栏里，旁边空着 | 证据表格占满可用宽度，说明文字放在上方 |
| 反色深色模式 | 深色模式只是把颜色反过来 | 为深色模式单独校对层级和对比度 |
| 只有 hover | 交互元素只有悬停变色，没有 focus 和 active 状态 | 补齐 hover、focus-visible、active、disabled 状态 |
| 功能清单式对比 | 方案页、对比页一上来就是十几行对勾表，用户要自己想「这对我有什么用」 | 先用一天或几个真实场景讲差别，传统对比折叠在后面 |
| 数据填充 | 为了显得丰富，加没用的数字、统计、图标、徽章 | 删掉；每个元素都要挣到位置，空就用构图解决 |
| 假系统界面 | 手机稿里画假的状态栏、电量、键盘 | 留出安全区，只画产品自己的东西 |
| 竖排挤压 | 两栏布局里一栏的值太长，把另一栏的标签挤成一个字一行 | 长值换成上下排的行，或换组件；用 verify_canvas 查 |
| 只画理想状态 | 只有数据齐全、一切顺利的那一屏 | 按状态矩阵补齐第一次、空、出错、降级、无权限 |
| 无菌极简 | 为了避开上面这些，只剩黑白细线和大片空白，没有焦点 | 克制不等于平淡：保留一个明确的视觉锚点，用比例、密度和节奏制造张力 |

注意最后一条：避开套路不是目标，做出有主张的设计才是。
