## 7. 规则缺口（不算问题，交主会话决定）

1. **V9 没有写「词中断行」**：第 3 轮合并表把词中断行算进第 5 类，但 V9 原文只写孤字、`balance`、`pretty`。本轮看到「队 / 列」「全因 / 死亡」「第一次 / 来」「直 / 接告诉我们」「项 / 目」。要不要写成规则（例如短元信息和链接加 `word-break: keep-all`），由主会话定。
2. **`verify_canvas.py --size` 只跑默认属性**：额外视口只查第一个状态、默认语言（第 396 行），所以看清英文 320 的按钮折行（X5）没被抓到。建议额外视口也跑 lang=English 和 pseudo。
3. **「孤字成行」检查的两个漏洞**：一个汉字加全角标点（「生。」）的宽度约 2em，超过 1.6em 的阈值，没报；`<a>` 之类的行内标题放在有块级兄弟的容器里时不在检查范围里（「课 / 程」）。建议按「最后一行去掉标点后只剩一个字」判断，并检查行内元素组成的标题。
4. **「竖排挤压」检查只看「宽度不到两个字」**：播放条里被挤成一词一行的「3-minute video」宽度超过两个字，没报；冲出圆角条的文字也不在「超出画板」的范围里。建议加「同一行控件里的标签折成 ≥ 3 行」和「文字超出所在圆角容器」两项。
5. **U2 的受众词要不要每个视口都看得到**：规则写「首屏或首屏说明里有」，矮屏收起导语以后算不算缺，规则没写；本报告按「首屏看得到」判。
6. **P4 的四帧只有浅色、只有收敛帧**：深色主题和过渡中的一帧没有证据；帧是用 SwiftShader 渲染的，不是真机 GPU。关口四在实现上补。
