# 看清（原同席博客）

这个仓库原来是博客「同席」（英文 With），现在是 Velicoach 主站，博客的文章归入「看清」一站（英文 Mind），不再单独起刊名。专有名词都用用户已经熟悉的词，见 [术语表](../GLOSSARY.md)。

看清的地址是 `velicoach.com/mind`，文章在 `velicoach.com/mind/<slug>`；旧地址 `with.velicoach.com` 永久跳转过来。视觉、版式、语言切换和主题都以 Velicoach 设计系统为准（[design-system.md](design-system.md)）。

## 留下的

- 一句描述：人和智能体一起工作、生活，把做法留下来。用在看清的首屏和分享卡上。
- 3 分钟视频的旁白：中文晓晓，英文 Andrew。它换的是声音，不是全站语言；全站是英文时默认 Andrew，是中文时默认晓晓。
- 收录文章的流程和约定：见 `AGENTS.project.md`「收录一篇时」。

## 改掉的

| 原来 | 现在 | 原因 |
|---|---|---|
| 站名「同席」，英文 With | 不另起刊名，就是看清；页面标题写「看清 · Velicoach」，英文「Mind · Velicoach」 | 同席听起来奇怪，With 太泛（11-04） |
| 页眉左侧放「同席」 | 页眉是 Velicoach 的胶囊导航 | 并入主站 |
| 主页第一屏是纸色加衬线，配一张木桌的横图 | 看清的首屏是墨色、衬线标题；阅读区跟随浅色、深色主题 | 设计系统「三站，三种底色」「浅色与深色」 |
| 语言按钮「中文、English」，只记在这一次浏览里 | 导航最右端的「中文 \| EN」，选择会被记住，英文在 `/en/` 下 | 设计系统「导航与语言切换」 |
| 没有英文稿的文章，英文页面显示中文正文 | 中英两版同时发布，英文页面不出现中文正文 | 主站 PRD 关键路径 P5 |

现有代码还是同席的旧首页；做主站页面时按本表一起改。
