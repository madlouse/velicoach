# 液态玻璃：做法、数值和退路

> 什么时候读：要给卡片、播放条、搜索框、工具栏、菜单、浮层、提示做「液态玻璃」材质时。这是换表面，不是改版式：标记、间距、圆角、字体、图标和文案都不动。配套文件：`assets/liquid-glass.css`（token 模板）、`scripts/liquid-glass.js`（边缘透镜和背景采样）。依据：苹果 HIG Materials、Polaris 的 bevel 做法、2026 年网页上实现 Liquid Glass 的公开实践。

## 0. 先盘点

- **列出所有压在图片、壁纸、视频或复杂背景上的表面**：卡片、播放器、搜索框、工具栏、菜单、浮层、提示，写清组件和位置。
- **找到浅色、深色怎么切换，颜色 token 放在哪里。** 玻璃做进 token，不写进每个组件。
- **平涂底色上的表面不动。** 背后是一种颜色时，玻璃只是一块灰。`verify_canvas.py` 的「玻璃压在平涂底色上」会把它报出来。背后是静态截图画不出来的东西（WebGL 动效、视频、滚动时才会压过的正文）时，在表面或它的祖先上写 `data-backdrop="motion"`（或 `video`、`scroll`）声明一下，检查会跳过它。
- **声明要成立，不是写上就算。** `motion`：表面要和一个 `canvas`（或标了 `data-motion` 的动效区域）重叠；`video`：要和 `video`、`[data-video]`、`.video-frame` 重叠或在它里面；`scroll`：表面或祖先要是 `sticky` / `fixed`。对不上时 `verify_canvas.py` 报「玻璃的背景声明不成立」。位置对得上也不等于背后会变：**表面跟着动效一起走（比如跟着接缝移动的圆），背后的比例不变，等于平涂**。用 `capture_motion.py <画板> out.png --probe <选择器>` 把表面藏起来连取几帧，背后亮度随时间的变化 < 0.04 就判「背后几乎不变」，改成实色面。
- **不叠玻璃**：玻璃上面不再放玻璃（吸顶导航下面再吸一条玻璃操作条、玻璃卡片里放玻璃按钮）。上面那层改成实色或墨色，同一时刻只有一层玻璃（HIG Materials）。
- 交付前先列一张表：哪些表面改成玻璃、哪些加透镜和色散、哪些保持实色，每条一句理由。

## 1. 材质做成 token

每种状态一组变量，表面用哪组就引用哪组。下面的数值是常规尺寸界面的起点。

| 状态 | 底色（tint） | 背景滤镜 | 边缘（box-shadow） |
|---|---|---|---|
| 浅色玻璃、深色字（默认） | 白色，透明度 6%–22%，按密度分档、每档 4% | `blur(2px) saturate(180%) brightness(1.06)`：颜色来自背后，保持鲜艳，不发白 | `inset 1.5px 1.5px 1px -1px` 白 95%；`inset -1.5px -1.5px 1px -1px` 白 55%；`inset 0 0 0 0.5px` 白 30%；`0 0 0 0.5px` 黑 6%；`0 6px 24px` 黑 8% |
| 浅色模式压在暗处、浅色字 | `rgb(16 18 22)`，10%–30% | `blur(2px) saturate(170%) brightness(0.85)` | 顶边一道淡白内线，外圈 0.5px 深色描边 |
| 深色模式 | `rgb(20 20 24)`，16%–38% | `blur(2px) saturate(160%) brightness(0.8)`：像和黑色正片叠底一样压暗，不发浑 | 和浅色同样的边缘和内光，强度约三分之一，描边和影子更深 |

- **内光**画在表面里面的一层上（伪元素或子层）：左上方一团径向高光（白 30%，到 55% 处淡完），再加一圈贴着边缘的柔和内发光，上边和左边亮一些，下边带一点暗。
- **墨色（ink）**：画在玻璃上的所有东西都用同一种颜色，分固定几档。

  | 玻璃 | 主墨（标题、图标、时间、进度） | 次墨 | 混合模式 |
  |---|---|---|---|
  | 浅色 | 黑 86% | `rgb(60 60 67)` 70% | `multiply` |
  | 深色 | 白 94% | `rgb(235 235 245)` 64% | `plus-lighter` |

  图标用不透明的颜色画，再整个图标降 `opacity`：半透明的颜色在笔画和填充重叠的地方会变深。
- **带品牌色的玻璃**（苔绿、品牌蓝这类底色）：品牌色的底色不透明度**不超过 50%**；超过这个上限背后已经透不出来，它就是一块实色，直接用实色按钮或实色面（同一个品牌色、不透明），不要再挂玻璃的滤镜和透镜。项目映射品牌色玻璃时把上限写进 token 旁边。
- **模糊按背后的内容分档**（数值是起点，按截图调）：

  | 表面 | 背后通常是 | 模糊 | 其他 |
  |---|---|---|---|
  | 小控件（按钮、圆、播放条，短边 < 80px） | 图片、动效、视频 | 2–4px | 透镜、内光照常 |
  | 导航条、吸顶工具条（`scroll`） | 滚过去的正文 | 16–24px | 字从后面滚过时要糊成色块，不能还认得出笔画；边缘加 8–12px 渐隐（`mask-image` 线性渐变），不画透镜 |
  | 通栏（宽度 > 约 600px 或左右贴边） | 图片、动效或正文 | 12–24px | 见下一条 |

- **通栏怎么做**：宽度超过约 600px 或左右贴边的条、底栏、全宽工具栏，**不画左上的径向高光和内光**（那是按圆角小表面写的，拉到通栏上是一条脏白边），只留顶边一道 0.5px 的淡白内线；底色**取背后的主色**（按 §4 采样，取不到时用主题底色），不用白色或黑色；对比度按背后**最差的那一块**（最亮或最花的一段）算，不按平均。
- **悬停、按下**：玻璃控件悬停把底色提亮约 14%（§2），按下再浓一档（浅色玻璃加白、深色玻璃压暗），都改玻璃自己的 token，**不叠灰色或黑色的状态蒙层**；实色按钮才用状态层。每个可点的玻璃控件都要有悬停、按下两条规则，`verify_canvas.py` 会报「可点元素没有悬停或按下样式」。
- **高亮行**是浅一层的玻璃：悬停叠白 42%，选中叠白 76% 加白色描边；不用灰色蒙一层。
- **用 `@property` 注册数值和颜色 token**（`syntax: '<color>'`、`'<number>'`），表面在状态之间平滑过渡，不跳。

## 2. 每个表面只改四个声明

- `background`：底色。
- `backdrop-filter`：材质的滤镜，**透镜 `url(#id)` 放在最后**，前面的颜色调整合成一遍，弯折保持清晰。
- `box-shadow`：边缘。
- `color`：墨色；里面画的所有东西加混合模式。

悬停时把底色提亮约 14%，不用加大影子来「抬起」。

## 3. 边缘透镜

- 每个表面一张**位移图**：红色是横向偏移，绿色是纵向偏移，128 是不动。只有边缘一圈弯，中间是平的。
- **边缘宽度** `rim = max(4, min(44, 短边 / 3.5))`。离边缘 `d` 的点向内看 `1.1 × rim × (1 - d / rim)^2.6`：边上最狠，背景像在边上折回来；到 rim 内沿减到 0，像一块厚玻璃。
- 位移图按 CSS 画的同一种圆角来算 `d`。用了 `corner-shape: superellipse()` 就按那条曲线算，不按圆弧，否则弯折和边缘光在角上对不上。
- 放进 SVG 滤镜：`feImage`（位移图）加 `feDisplacementMap`，`scale = 2 × 最大偏移`；再把 `url(#id)` 加到 `backdrop-filter` 末尾。
- **色散**：分三遍，红色多偏 15%，蓝色少偏 15%，每遍用 `feColorMatrix` 只留自己的通道，再用 screen 叠回去。在宽边缘、复杂背景的角上检查；变成一团雾时就减小色散。
- **浏览器**：只有 Chromium 会画 `backdrop-filter` 里的 `url()`。判断 `CSS.supports('backdrop-filter', 'url(#a)')`，再排除 Firefox（认得写法却什么都不画）；Safari 的 `@supports` 也会通过却不画，所以同时要求是 Chromium 内核。别的浏览器只留纯 CSS 的玻璃。
- **滤镜区域比表面大一圈**（`liquid-glass.js` 按表面长边各向外放一倍）：区域只要比表面小一点（量的时候还没排完版、吸顶偏移、缩放取整），区域外的像素变成透明，背后的正文会不经模糊直接透出来。
- **吸顶玻璃的祖先不能是另一个「背景根」**：祖先上有 `filter`、`opacity < 1`、`mask`、`backdrop-filter` 或 `will-change` 时，模糊只取到那一层为止，滚过去的正文糊不掉。实现时用 `capture_motion.py --scroll` 在 Chromium 截，关口四在 Safari、Firefox 真机上再看一次。
- **等位移图解码完**再把表面指向滤镜，否则会画出没有模糊的样子。每个滤镜一个唯一 id、放在自己的 `<svg>` 里。位移图按「圆角 × rim」缓存复用；尺寸变了只移动位移图，不重建。
- **不加透镜**：小于 32px 的表面；有 `will-change` 或自己合成层的表面（菜单、做动画的面板），Chrome 在那里可能把位移图本身画出来，而不是弯折后的背景。

## 4. 按背后的内容自适应

- 每个表面在它背后按 **5 × 3 网格**取样，去掉最暗和最亮各两个点，取平均。亮度 = `(0.299 R + 0.587 G + 0.114 B) / 255`；纹理 = 最亮点减最暗点。
- **墨色**：浅色模式下亮度低于 0.5 用浅色字。当前墨色在 0.5 上下 ±0.05 以内保持不变，不在线上来回闪。深色模式一律浅色字。同一行相邻的表面共用一个决定。
- **密度**（0 薄，1 浓）= `0.55 × 背景亮度和墨色本身亮度有多接近 + 0.7 × 纹理 + 0.3 × 色度`，在薄、浓两档透明度之间取值。
- **保留的饱和度** = `max(0.45, 1 - 0.75 × 色度)`：背景很艳时玻璃不被染色。
- 背景、主题或表面位置变了就重新取样；记住上一次的墨色，下次打开直接用。
- 背景读不到（直播视频、跨域内容）：按主题选墨色，用浓的那一档。

## 5. 浓度由设计定，默认不给用户调

- 浓度和配色是设计的责任：在 token 里按浅色、深色各调好一档，用最忙、最暗的背景验到 4.5:1。用户不需要、也不应该替设计调参数，所以默认**不做浓度设置**。
- `--lg-tint-scale-light`、`--lg-tint-scale-dark` 只作为设计内部的总旋钮（调整整体浓度时改一个数），默认 1。
- 只有产品明确要求（例如面向专业用户的工具）才把它做成设置项；那是需求改动，先问产品负责人。没人提就不提，也不要把它当成待决事项去问。

## 6. 无障碍

- 在产品允许的最忙、最暗的背景上，按默认浓度检查文字对比度（正文 4.5:1，大字 3:1）；不够就**提密度**，不提墨色的透明度。
- `prefers-reduced-transparency: reduce` 和 `forced-colors: active`：换成同色、完全不透明的实色面，去掉透镜和内光。Safari 读不到「降低透明度」，所以默认浓度本身就要让字过线。
- 焦点环、禁用、错误色照旧：出错还是红色。

## 7. 交付

1. 先列表面：改成玻璃的、加透镜和色散的、保持实色的，各写理由。
2. 再加 token 和透镜工具，把表面换过去，列出改过的每个文件。浓度在 token 里调好，不做用户设置。
3. 不改版式、字体、圆角和文案。哪个表面要新组件才能做成玻璃，先停下来问。
4. 检查：`verify_canvas.py`（含「玻璃压在平涂底色上」「玻璃的背景声明不成立」「可点元素没有悬停或按下样式」）在浅色、深色下为 0；在最忙、最暗的背景上截图量对比度；模拟降低透明度截一张。
5. **按背后的种类交证据**，截图都用 `scripts/capture_motion.py`（它会跑画板完整的 `componentDidMount`，等透镜的位移图解码完再截；静态截图工具不跑挂载代码，截不到透镜和动效）：
   - `motion`：动效跑起来的一帧，加 `--probe <表面>` 的结果（「背后会变」）；再截 `--reduced-motion` 的静止帧和 `--no-webgl` 的兜底画面。
   - `video`：视频最亮、最暗的两帧各一张。画板里没有真视频时，给视频框加一个 `frame` 属性（封面 / 最亮一帧 / 最暗一帧），帧是和播放条同级的元素（真实页面里的 `<video>` 也是），不要写成播放条的父元素背景；用 `capture_motion.py --props` 截两帧，量播放条空白处最亮的像素和白字的对比度。视频读不出像素，播放条用浓的一档（`--lg-density: 1`），下面垫一段墨色渐变压暗，最亮的一帧上也要过 4.5:1。
   - `scroll`：**正文的一行字正好从玻璃文字后面滚过**的那一刻。画板要有一个把内容往上移的属性（例如 `data-props` 里的 `scrolled`，按选项给正文一个负的 `margin-top` 或 `transform`，让第一段正文的某一行落在吸顶条的文字后面），用 `--props` 切到那个选项截图，并在那张图上量玻璃上文字的对比度。只是「滚过了首屏」、条后面是空白的截图不算。

## 接入

```html
<link rel="stylesheet" href="liquid-glass.css">  <!-- 把 --lg-* 映射到项目的 token -->
<div class="lg lg-light">…</div>
<script type="module">
  import { attachLens, adaptInk } from './liquid-glass.js';
  for (const el of document.querySelectorAll('.lg')) { attachLens(el); adaptInk(el, document.querySelector('#hero-img')); }
</script>
```
