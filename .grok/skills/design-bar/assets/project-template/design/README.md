# design/

本目录记录这个项目的设计工作。设计语言本身在 Claude Design 的设计系统里（链接见 `design-system.md`），这里放的是确认过的需求、标杆、评审证据和决策。由 design-bar 技能创建和维护。

## 阅读顺序

1. `design-system.md`：设计系统的链接、代码里 token 的位置、同步时间。
2. `brief.md`：已确认的产品与用户信息。
3. `bar-sheet.md`：标杆卡，说明「好」的标准从哪里来。
4. `decisions.md`：设计决策与变更记录。

## 目录

| 路径 | 内容 | 什么时候更新 |
|---|---|---|
| `design-system.md` | 设计系统链接、token 路径、画布链接 | 建立设计系统、每次同步 |
| `brief.md` | 七项已确认信息与待确认问题 | 用户确认后 |
| `bar-sheet.md` | 参考拆解、标杆原则、明确不做 | 方向变化时 |
| `features/` | 每个功能一份设计简报 | 开始做新功能或打磨旧功能时 |
| `reviews/` | 每轮评审的检查报告和截图 | 每次评审 |
| `decisions.md` | 决策日志 | 每次被接受的设计决定 |

## 维护规则

- 设计语言只在设计系统里改；代码里的 tokens.css 由 `sync_tokens.py` 生成。
- 评审中同一类意见出现两次以上，写回设计系统（规则或 token）或检查阈值，而不是只改当前页面。
- 截图较大时，只保留最近一轮的完整截图，旧轮次保留 `report.md` 即可。
