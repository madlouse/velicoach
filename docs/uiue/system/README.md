# Velicoach

AGI 路上的陪练：先站稳，再看清，然后动手。

这套设计系统管 velicoach.com 主站和它的三站：站稳、看清、动手（英文 Body、Mind、Build），三个站名就是口号「先站稳，再看清，然后动手」里的三个动作。其他专有名词都用用户已经熟悉的词，中英文都能一眼看懂。Veli App 和 Veli 网页版仍以 Veli 设计系统为准；两套系统共用叶子标识、纸色、苔绿和主按钮的样式。为了不和 Veli 的 token 重名，这里的颜色都以 `vc-` 开头。

## 一句话原则

**每屏只讲一件事，只有一个主动效。** 文字先出现，动效后加载；动效只是陪衬，没有它页面照样完整。

**核心操作两步内完成，不常用的不超过三步。** 一步是一次有意的点按或提交，滚动和打字不算。按钮直达结果，不经过中间页；首屏就把核心操作的入口摆出来，登录后同样的位置换成「继续」。逐个场景的步数表在主站 PRD 第 4 节「步数预算」。

## 三站，三种底色

从左到右，是一天从晨练到夜读，也是「先站稳，再看清」。三种底色只在各自的站里用，首页把前两种拼在一起，第三种是两者的交汇点。

| 站 | 底色 | 正文 | 强调色 | 字体 | 气质 |
| --- | --- | --- | --- | --- | --- |
| 01 站稳 | `vc-paper` | `vc-text` | `vc-moss` | 无衬线（SF Pro Display、苹方） | 晨练：克制、可信 |
| 02 看清 | `vc-ink` | `vc-on-ink` | `vc-cinnabar` | 标题衬线（New York、宋体），正文无衬线，代码等宽 | 工程师的书房：极简、克制、有品味 |
| 03 动手 | `vc-moss-hero` | `vc-on-moss` | `vc-amber`、`vc-moss-light` | 无衬线 | 交汇处：行动 |

- 全站和产品都有浅色和深色两种主题，默认跟随系统（规则见「浅色与深色」）。
- 三种底色是各站的身份，用在首屏的品牌色带上：首页左半纸色、右半墨色，看清的首屏是墨色，动手的首屏是苔绿。色带以下的阅读区、列表、卡片和表单都跟随主题。
- 一种强调色只在自己的底上出现：朱砂只放在墨底，琥珀只放在苔绿底。朱砂要出现在纸底时，用 `vc-cinnabar-deep`。

## 内容与语气

- **对外只放正式版。** 不留占位符，不写过程性说明，不出现「示例」「待定」。
- **用行业通用的词。** 栏目、按钮和专有名词都用用户已经熟悉、业界通用的说法，中英文都能一眼看懂：订阅（Newsletter）、开发日志（Devlog）、里程碑、学习路径、今天的训练、3 分钟视频；AI 术语按行业标准写，如智能体（agent）、提示词工程、上下文工程。三个站名站稳、看清、动手（Body、Mind、Build）就是品牌口号，是例外。不另起需要解释的名字，看清也不另起刊名。完整的词表在主站仓库的 `docs/GLOSSARY.md`。
- **不造词。** 术语第一次出现时带一句白话，例如「智能体（agent）：能自己调用工具、把一件事做完的 AI」。
- **中英双语。** 每段对外文字都有两版；英文按英语读者重写，不逐字直译；用词以 PRD 的术语表为准。
- **具体，有出处。** 数字带单位；健康研究写明研究类型、样本量和年份，例如「Cochrane 系统综述，2019 · 59 项试验」。
- **讲力量，不讲身材；不制造焦虑。** 与 Veli 一致：写「每周 30–60 分钟力量训练」，不写「再不练就晚了」。
- **一句话只讲一件事。** 中文导语每行不超过 32 个字。

## 看清的气质

看清讲 AI 的发展史和人机协作，气质是**工程师的书房：极简、克制、有品味**。这里的品味指对技术的判断，不指某种网站样式。我们参考的是陈皓（酷壳、「左耳听风」的作者）的技术品味，不照搬酷壳的页面；下面每一条都从他的一个判断出发，落到看清要做成什么样。

| 他的判断 | 看清怎么做 |
| --- | --- |
| 学习不只是要答案，而是学方法 | 学习路径的每一步写清楚为什么学、学到什么程度、怎么检验自己学会了；文章先讲原理，再讲用法；每篇留一个读者能自己动手验证的练习，做完可以带去动手一站 |
| 这件事没有捷径，也不可能速成 | 不做「三天学会」；学习路径标出大概要花的时间；里程碑讲清一件事为什么是路线的转折、改变了什么，不堆新闻 |
| 蛮力弥补不了思维和眼界 | 人机协作按工程范式的演进组织（提示词工程 → 上下文工程 → Harness 工程 → Loop 工程 → Graph 工程），先给读者一张地图，再给工具；不做工具清单 |
| 从自己做过的事出发，有观点 | 工程实践只收有真实落地、写了代价的案例；我们自己用智能体做 Veli 和这个站，过程写进开发日志；每篇给明确判断，包括「不推荐」 |
| 知识最好被检索、讨论、引用、整理、补充和更新 | 每篇有发布日期、更新记录和「适用于」（模型、版本）以及最后核对日期；每个小节有锚点，能链接到具体一段；引用都有出处；读者能直接指出错误；每条内容线可以用 RSS 订阅 |
| 想做好，再轻的事也会变重 | 代码块、排版、错别字、加载速度都按工程质量对待，发布前逐项检查 |
| 我不是高手 | 没验证过的写明没验证过；不懂的不写；读者指出的错误公开改正，记在更新记录里 |

由这些判断推出页面的样子：

- **内容是主角，界面退后。** 首屏一条墨色色带，只放站名、一句描述和两条内容线（AI 发展史、人机协作）；没有主图、插画和动效，不加载 three.js。
- **为扫读和检索排版。** 文章和里程碑一行一条：等宽的日期、标题、一句话，整行可点，行尾直接放「3 分钟视频」。学习路径和论文清单要比较，所以用能排序的表，表格只用横线。
- **出处是正文的一部分。** 引用用脚注；桌面宽度（1180px 以上）放到正文右侧作侧注（`sidenote-width`），手机和平板放回文末。
- **克制。** 字体三种：衬线标题、无衬线正文、等宽代码。颜色三种：墨、纸、朱砂，朱砂只给链接和「当前所在」，链接加细下划线。强调只用粗体。
- **代码像在编辑器里。** 等宽、低饱和高亮、能复制、长行横向滚动不折行。
- **不打扰。** 不弹窗，读文章不需要登录；订阅邮件和 RSS 由读者自己选。
- **页面轻。** 文章页首屏只有文字，不依赖脚本也能读；除图片外一篇文章传输不超过 150 KB。

## 字体

苹果设备上直接用系统字体；其他设备用 Google Fonts 里风格相近的字体作为回退（Inter Tight、Noto Sans SC、Noto Serif SC、IBM Plex Mono）。

| 用途 | 样式 | 字号 / 行高 / 字重 |
| --- | --- | --- |
| 首页与站稳的主标题 | `hero-body` | 80 / 1.08 / 700，字距 -0.025em |
| 首页与看清的主标题 | `hero-mind`（衬线） | 80 / 1.1 / 600 |
| 分站首屏标题 | `title-1` | 64 / 1.12 / 700 |
| 区块标题 | `title-2`；看清用 `serif-title-2` | 40 / 1.2 |
| 卡片标题 | `title-3`；看清用 `serif-title-3` | 24 或 22 |
| 导语 | `lead` | 19 / 1.7 |
| 正文 | `body` | 16 / 1.7 |
| 出处、日期 | `footnote` | 13 / 1.5 |
| 栏目标记 | `kicker`；看清用 `meta-mono` | 13，字距 0.06em |

首屏倾斜时，两侧主标题的字号随分割比例在 44–84px 之间连续变化：展开的一侧变大，收起的一侧变小。

## 玻璃材质

**玻璃只给浮在内容上面的那一层。** 正文和卡片不用玻璃，否则既难读，又显得廉价。

| 层 | token | 用在哪里 |
| --- | --- | --- |
| 常规玻璃 | `vc-glass` + `blur-glass` | 首页跨在接缝上的胶囊导航、站稳页的悬浮顶栏 |
| 厚玻璃 | `vc-glass-thick` + `blur-glass-thick` | 3 分钟视频的播放条、浮层 |
| 苔绿玻璃 | `vc-glass-moss` + `blur-glass` | 「动手」圆 |
| 墨色玻璃 | `vc-glass-ink` + `blur-glass` | 看清页的悬浮顶栏 |

- 每块玻璃都配 `shadow-glass`：顶边 1px 高光、外圈 1px 亮边、下方一层浮起的影子。背景模糊的同时把饱和度提到 180%，背后的颜色透过来更通透。
- 浏览器不支持背景模糊，或用户打开「降低透明度」时，浅色玻璃换成 `vc-glass-fallback`，苔绿玻璃换成 `vc-moss-hero` 实色。
- 玻璃上的文字按最差的背景算对比度：浅色玻璃压在墨色上仍有 6.6:1；苔绿玻璃上的琥珀编号压在纸色上仍有 4.6:1。

## 版式

页面内容最宽 1120px（`content-max`），正文段落最宽 640px（`text-max`）。可点元素至少 44px 高；主按钮 50px，胶囊形。**一个区域只有一个主按钮**，它的文字写点了之后得到什么（「进入今天的训练」），不写「了解更多」；同一区域的其他入口用文字链接。首屏左右两半是两个区域，各有一个主按钮和两三个快捷入口，首屏底部一行是订阅，点「订阅」后邮箱框原地展开。

### 三种版式

按可用宽度分三档，不按设备型号判断。iPad 分屏、台前调度把窗口变窄时，自动落到对应的档。

| 版式 | 宽度 | 边距 | 栅格 | 首屏 | 卡片 |
| --- | --- | --- | --- | --- | --- |
| 手机 | 小于 744px | `gutter-phone` 16px | 4 栏 | 上下拼接：上半纸色、下半墨色，「动手」圆压在接缝中央 | 单列 |
| 平板 | 744–1179px | `gutter-tablet` 32px | 8 栏 | 左右各 50%，两侧说明文字和按钮全部显示，不倾斜 | 两列；第三张占满一行 |
| 桌面 | 1180px 及以上 | `gutter-desktop` 48px | 12 栏 | 左右各 50%，可倾斜（见下） | 三列 |

- **倾斜只给有悬停的设备。** 只有同时满足 `(hover: hover)` 和 `(pointer: fine)` 时，鼠标进入哪一侧，那一侧才展开到 62%，另一侧退到 38% 并收起说明文字。触屏的 iPad 横屏虽然够宽，也保持 50/50、全部内容可见，点一下直接进入那一站。接了触控板的 iPad 按桌面处理。
- **进入一站后**，桌面和平板上另一站收成 56px 宽的书脊（`spine-width`），点书脊直接换过去；手机上不放书脊，换站用顶部导航。
- **首屏高度**用 `100svh`，避开手机浏览器地址栏伸缩造成的跳动；内容避开安全区（`env(safe-area-inset-*)`）。
- **字号随档位收紧**：主标题在手机上 44px、平板 64px、桌面 80px；导语在手机上 17px。正文三档都是 16px，不缩小。
- **横竖屏切换**不重新加载动效，只重新计算画布尺寸和叶子的大小。

### 导航与语言切换

胶囊导航用常规玻璃，高 52px（`nav-height`），桌面上跨在首屏接缝上，平板和手机上居中贴顶。三档都不用汉堡菜单：

- 内容从左到右是叶子标识、三站入口（站稳、看清、动手；英文 Body、Mind、Build）、搜索、登录（登录后是头像，点开是账号菜单：订阅开关、账号与隐私、退出）、语言切换。手机上搜索和登录只显示 44px 的图标，375px 宽也能一行放下。
- 登录在当前页面原地弹出 Google 和 Apple 两个按钮，不跳到单独的登录页；登录后留在原来的页面。
- **语言切换用分段控件「中文 | EN」，放在导航最右端。** 只有两种语言时，分段控件一眼看到当前语言，一下就切过去；下拉菜单要先点开再选，多一步还藏起了状态。手机上缩成「中 | EN」。
- 两个选项都用语言自己的名字，不随界面语言翻译，也不用国旗。
- 两个选项是指向对应语言版本的链接，带 `hreflang`，当前语言标 `aria-current="true"`；切换后停在同一页面的另一语言版本，滚动位置回到顶部。
- 支持的语言达到三种时，换成地球图标加菜单，菜单里每种语言用它自己的名字列出。

### 原地展开

一个入口后面有几个去处时（例如「开始第一练」：在网页上登录，或在手机上下载 App），不跳到页面下方或另一页去选，而是在入口旁边直接给出选项，每个选项都直达结果。

- **有悬停的设备**：入口保持一个紧凑的按钮。鼠标停留 80ms 后，选项卡片在按钮下方展开；鼠标可以移进卡片，离开 300ms 后收起，按 Esc 立即收起。悬停本身不算一步。
- **键盘**：聚焦按钮就展开，Tab 进入选项。
- **触屏**：没有悬停，选项直接摆在按钮的位置，不需要先点开。手机上能判断系统时，只给对应的登录方式和应用商店。
- **悬停只是更快，不是唯一的路**：展开的内容同样能用点按和键盘打开，符合 WCAG 2.2 的 1.4.13（可关闭、可移入、不自动消失）。
- **预先连接**：悬停或聚焦时，提前连接下一步要用的地址（例如登录服务），点下去立刻打开。
- 选项卡片用厚玻璃，最宽 560px，不遮住主标题。
- 只有一个去处的入口不做展开，直接去；正文里的链接不做展开。

用到的地方：「开始训练」（首页站稳一侧、站稳页首屏和导航）、账号菜单、看清一侧的两条内容线（展开后列出每条线最新的三篇，点了直接读）。

### 少一步的做法

两步原则靠下面这几种做法落地，按场景选用。新页面先在 PRD 的步数表里数步数，超了就从这里找办法，不改预算。

| 做法 | 什么时候用 | 规则 |
| --- | --- | --- |
| 直达 | 按钮只有一个去处 | 链接到结果所在的状态（今天的训练、文章里上次读到的位置），不经过介绍页 |
| 原地展开 | 入口后面有几个去处 | 见上一节 |
| 列表和卡片里直接操作 | 一条内容代表一件能马上做的事 | 看清的文章列表每一行末尾直接放「3 分钟视频」，点了就在原地播放；今天的训练卡片上直接「开始」；点其他地方才进详情 |
| 原地切换 | 同一页里换一组内容 | 看清的两条内容线、开发日志的项目筛选用分段控件切换，内容原地替换，地址跟着变，可以分享和后退；列表底部「再看 10 篇」原地追加，不翻页 |
| 卡片展开成页面 | 从卡片进入详情 | 用浏览器的视图过渡（View Transitions），卡片的标题和图连续地长成文章页的标题和图，用户感觉是同一张卡片打开了，不是跳到另一页；悬停或按下时预先加载目标页，点下去立刻出现 |
| 认出回来的人 | 已经登录过的用户 | 用 Google 一键登录（One Tap）自动登录，或用通行密钥（passkey）在输入框里直接选，省掉选账号这一步；登录后首屏换成「继续」 |
| 记住选择 | 语言、主题、上次读到哪 | 选一次，以后不再问；跨设备的只记账号相关的，主题按设备记 |
| 本站的操作条 | 三站的首页滚过首屏后 | 顶部胶囊导航下方出现本站的玻璃操作条：左边是本站名和栏目，右边是本站的主操作（站稳是「开始训练」）。和 apple.com 产品页的本地导航一样，主操作一直在手边，不用滚回顶部 |
| 撤销代替确认 | 能撤回的操作 | 不弹「确定吗」，直接执行，底部给 5 秒的「撤销」；删除账号这类撤不回的仍然要确认 |
| 搜索即命令 | 想去任何地方、做任何事 | 导航里的搜索（桌面上按 ⌘K）同时搜文章和操作，例如「开始训练」「切换到英文」「深色模式」，选中就执行 |

不采用：左右滑动切换三站（和表格、代码块的横向滚动冲突，也和 iOS 的返回手势冲突，又看不出来能滑）；长按预览（触屏上没人知道要长按）；用浮层打开文章（地址不能分享，搜索引擎也看不到）；无限滚动（页脚永远到不了，搜索引擎也难收录）。

### 浅色与深色

- **默认跟随系统。** 浏览器通过 `prefers-color-scheme` 告诉页面系统是浅色还是深色，Safari、Chrome、Edge、Firefox 都支持，手机和电脑一样。系统切换时页面立刻跟着变，不用刷新。
- **读不到时用浅色。** 浏览器不报告系统偏好时，用浅色：纸色是品牌的主色，首页纸墨两半的对比在浅色下最清楚，白天读长文也更舒服。
- **可以手动选。** 三个选项：自动、浅色、深色，默认自动。放在页脚和账号菜单里，搜索里输入「深色」也能直接切换；切换是低频操作，一步到位即可，不占导航的位置。选择按设备记住。
- **不闪。** 页面在绘制之前就读出保存的选择并设好主题（`<head>` 里的一小段脚本），声明 `color-scheme: light dark`，并按主题给浏览器顶栏设 `theme-color`。
- **品牌色带在深色下降亮度，不换颜色。** 首页左半在深色下用 `vc-hero-body` 的暗纸色，夜里不刺眼，和右半的墨色仍然分得开；看清的墨色首屏、动手的苔绿首屏两种主题都一样。
- **阅读区跟随主题。** 看清的文章在浅色下是纸底、衬线标题、深朱砂强调（`vc-cinnabar-deep`）；在深色下是墨底、亮朱砂强调。
- 「叶与网」的点按落在哪一侧取颜色，颜色都来自 token，两种主题都要单独看一遍效果。
- 交付时每个页面都截浅色、深色两套图。

### 语言版本的规则

- 中文在根路径，英文在 `/en/` 下，两版一一对应；每页都声明 `lang` 和互指的 `hreflang`。
- 第一次访问首页时按浏览器语言选版本；用户手动切换过就记住选择，以后不再自动跳转。直接打开某个具体页面时不自动跳转，避免搜索引擎和分享链接拿到错的版本。
- 中英两版同时发布，不出现「英文版即将上线」之类的半成品页面。

## 动效

**每屏一个主动效。** 首页的主动效是「叶与网」：Veli 的叶子由几千个点组成，首屏向右倾斜时散开、重组成一张网，向左时又长回一片叶子；每个点的颜色取决于它落在哪一侧。站稳和动手的首屏只用「墨入纸」的纸墨质感，几乎静止；看清的页面没有任何动效，也不加载 three.js。

没有悬停的设备（手机、触屏平板）上不会倾斜，叶与网改为跟着呼吸周期缓慢往返：先是叶子，散开成网，再长回叶子，不需要用户操作。

| 动效 | 时长 | 缓动 |
| --- | --- | --- |
| 悬停、按压 | `duration-fast` 150ms | `ease-out` |
| 展开、切换 | `duration-base` 240ms | `ease-out` |
| 首屏倾斜 | `duration-lean` 600ms | `ease-out` |
| 「动手」圆回弹 | `duration-spring` 420ms | `ease-spring` |
| 主动效的呼吸 | `duration-breath` 10 秒一个周期 | 正弦 |

**技术与底线**

- three.js 的 WebGPURenderer 加 TSL 着色器，同一份代码在 WebGPU 和 WebGL2 上都能跑；两者都不可用时显示静态画面。
- three.js 在首屏文字绘制完成后再加载，不拖慢最大内容绘制。
- 滚出视口或切到别的标签页时暂停；帧率持续低于 40 时，把像素密度降到 1 倍。
- 中端手机上每帧不超过 4 毫秒；手机上粒子数减半。
- 系统打开「减弱动态效果」时，只画一帧静态画面，倾斜也不做过渡。

## 标识与图标

- 标识沿用 Veli 的「叶脉成 V」：一片沿 45° 对称的叶子，两条叶脉在负形里夹成 V。纸底上用 `vc-moss`，苔绿底上用 `vc-moss-light`。
- 图标用 1.5px 线宽的线性图标，跟随文字颜色；不用 emoji 当图标。

## 无障碍

- WCAG 2.2 AA：文字对比度 4.5:1 以上；每个颜色 token 的说明里都写了它在自己底色上的对比度。
- 焦点环用 `vc-focus`，2px，向外偏移 2px。
- 只用键盘能完成全部操作；按 Esc 回到首屏的五五分。
- 3 分钟视频有字幕和文字稿；图形和动效都有文字说明，读屏时跳过装饰性的画布。
