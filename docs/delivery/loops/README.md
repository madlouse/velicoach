# 流水线的定时任务

每个文件是一个云端定时任务的配置和提示词（`docs/standards/pipeline.md` §4）。改提示词先改这里，再同步到定时任务。什么时候开见 `pipeline.md` §8：关口三通过、前置票做完以前，一个都不开。

| 文件 | 循环 | 主会话模型 | 定时（纽约时间） |
|---|---|---|---|
| `site-runner.md` | ① 站点票推进器 | Sonnet 5.5 | 每 2 小时的 :41，拉起后连续推进 |
| `content-runner.md` | ② 内容推进器 | Sonnet 5.5 | 每天 9:13 |
| `daily-digest.md` | ③ 日报 | Haiku 5.5 | 每天 7:37 |
| `observer.md` | ④ 观察者 | Opus 5.5 | 每天 7:07 |

定时和 Veli 的四个任务（票推进器每 2 小时的 :17、观察者 6:47、日报 7:23）错开，避免同一时刻抢用量；产品负责人早上先看 Veli 的日报，再看主站的。
